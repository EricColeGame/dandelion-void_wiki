## What to Check Before You Install

Rather than chasing exact numbers, focus on the categories that actually decide whether the game runs. Requirements shift between patches, so verify them on the listing page on the day you download.

| Component | What to look for | Warning sign |
|---|---|---|

| Storage | Free space plus room for saves and patches | Less than 10% free after install |

Player experience consistently points to storage and RAM as the two most common bottlenecks. A machine that technically meets the minimum can still stutter if the drive is nearly full or if background apps are competing for memory. Closing a browser and freeing a few gigabytes often does more for smoothness than lowering graphical settings.

## Troubleshooting the Most Common Dandelion Void Download Problems

When something goes wrong, the symptom usually points to a specific cause. Work through this table before you start deleting things.

| Symptom | Likely cause | Fix |
|---|---|---|
| Download stalls at a fixed percentage | Connection drop or server-side throttle | Pause, resume, or switch networks and retry |
| "File is corrupt" on install | Incomplete transfer | Delete the partial file and re-download from the same source |
| Game launches, then closes immediately | Missing runtime or driver conflict | Update graphics drivers and platform runtimes |
| Black screen with audio | Resolution or fullscreen mismatch | Launch in windowed mode via startup options |
| Antivirus flags the installer | Heuristic false positive or genuine tampering | Re-download from the official source; if flagged again, stop |
| Save file not detected | Wrong install path or cloud sync conflict | Check the save directory and disable cloud sync temporarily |

If a fix works, write it down. Indie titles with smaller support teams often rely on community documentation, and the solution that helped you will help the next person searching for the same error.
